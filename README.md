# Dugout Hub

Jaxson's baseball training hub: https://mbeat1mb-debug.github.io/dugout-hub/

- `dugout-hub/index.html` is the app, one self-contained page.
- `dugout-hub/src/` holds the source: `page.html`, `app.js`, `logic.js`. Rebuild with `python3 dugout-hub/src/build.py dugout-hub/index.html`.
- Data lives in a private database behind a family code. No data or code is stored in this repository.
